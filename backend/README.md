# Backend - Sistema Inteligente de Análisis de Cadmio

## Tecnologías
- NestJS + TypeScript
- PostgreSQL + Prisma
- Socket.io (tiempo real)
- JWT + Refresh Tokens
- class-validator / class-transformer
