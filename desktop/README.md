# App de Escritorio - Sistema Inteligente de Análisis de Cadmio

## Tecnologías
- Electron
- React 18 + TypeScript
- Tailwind CSS
- Recharts (gráficos)
- React Router
- Axios + Socket.io-client

## Estructura (se completará en Fase 3 y 4)

